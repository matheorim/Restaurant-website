# Restaurant Website

🇫🇷 [Version française](README.fr.md)

A small static website for a fictional gourmet restaurant, built with HTML and CSS during the first semester of a BUT Informatique (Bachelor of Technology in Computer Science) at the IUT Grand Ouest Normandie, Caen. The site content is in French.

> **Context:** this is one of my very first web projects. I had only just learned the basics of HTML and CSS, and I built the site in **less than two hours** in a practical session. That is why the design is simple and the site is unfinished. I publish it to show where I started, and my later projects show how far I have come.

**Live demo:** https://matheorim.github.io/restaurant-website/

## Pages

| Page | Content |
|---|---|
| `index.html` | Home page with the navigation menu |
| `presentation.html` | Presentation of the chef and of the restaurant's philosophy and atmosphere |
| `galerie.html` | Photo gallery (dishes, dining room, team) with captions |
| `formulaire.html` | Table reservation form |
| `contact-mentions-legales.html` | Contact and legal notices (unfinished) |

## What this project covers

- Semantic HTML structure (`header`, `main`, `nav`, `footer`)
- Navigation between several pages
- Lists (ordered and unordered), images and form inputs
- A single shared stylesheet (`styles.css`): background image, flexbox layout, hover effects

## Known limitations

Because of the very limited time and my beginner level at that point:

- The reservation form is not functional (no JavaScript and no server side)
- The contact page is incomplete
- The footer does not display the date and time
- The styling is basic (no responsive design, no custom layout)

## Run locally

No build step is needed. Download the project and open `index.html` in a web browser.
