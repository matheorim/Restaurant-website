# Site web de restaurant

🇬🇧 [English version](README.md)

Petit site web statique pour un restaurant gastronomique fictif, réalisé en HTML et CSS pendant le premier semestre de BUT Informatique à l'IUT Grand Ouest Normandie (Caen).

> **Contexte :** c'est l'un de mes tout premiers projets web. Je venais d'apprendre les bases du HTML et du CSS, et j'ai réalisé ce site en **moins de deux heures** lors d'une séance de TP. C'est pourquoi le design est simple et le site inachevé. Je le publie pour montrer mon point de départ, et mes projets suivants montrent ma progression.

**Démo en ligne :** https://matheorim.github.io/restaurant-website/

## Pages

| Page | Contenu |
|---|---|
| `index.html` | Page d'accueil avec le menu de navigation |
| `presentation.html` | Présentation du chef, de sa philosophie et de l'ambiance du lieu |
| `galerie.html` | Galerie de photos (plats, salle, équipe) avec légendes |
| `formulaire.html` | Formulaire de réservation de table |
| `contact-mentions-legales.html` | Contact et mentions légales (inachevée) |

## Notions abordées

- Structure HTML sémantique (`header`, `main`, `nav`, `footer`)
- Navigation entre plusieurs pages
- Listes (ordonnées et non ordonnées), images et champs de formulaire
- Une feuille de style commune (`styles.css`) : image de fond, mise en page flexbox, effets au survol

## Limites connues

À cause du temps très limité et de mon niveau débutant à l'époque :

- Le formulaire de réservation n'est pas fonctionnel (ni JavaScript, ni serveur)
- La page de contact est incomplète
- Le pied de page n'affiche pas la date et l'heure
- Le style est simple (pas de design adaptatif, pas de mise en page personnalisée)

## Lancer en local

Aucune compilation n'est nécessaire. Télécharge le projet et ouvre `index.html` dans un navigateur.
